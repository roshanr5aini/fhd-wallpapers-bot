FHD Wallpapers Bot — Music Finder Update

Environment variables required on Render:
- BOT_TOKEN
- SERPAPI_KEY
- REMOVE_BG_API_KEY
- SHAZAM_API_KEY

Optional:
- SHAZAM_API_BASE=https://shazam-api.com
- MUSIC_POLL_SECONDS=1.5
- MUSIC_POLL_ATTEMPTS=12

Music recognition uses Shazam-API v2:
POST /api/v2/recognize
GET  /api/v2/results/{uuid}

Text title/artist search uses Apple's public iTunes Search API.
Lyrics mode uses SerpAPI Google search to find likely matches and links/snippets.

This implementation does NOT download/rip full copyrighted songs. It shows available official/music links and catalog previews where provided by the source.

Deploy:
1. Replace your current main.py with this main.py.
2. Keep the existing requirements.txt (or use the included one).
3. Add SHAZAM_API_KEY in Render Environment Variables.
4. Deploy.
5. Use /start and select 🎵 Music Finder.
